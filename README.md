# Leab Studios — sitio web

Sitio estático (HTML + CSS + JS sin dependencias). Abre `index.html` directamente o sírvelo con cualquier hosting estático (Netlify, Vercel, GitHub Pages).

- `index.html` — estructura y contenido
- `assets/css/styles.css` — estilos (logos y tipografías embebidos para que funcione también sin servidor)
- `assets/js/main.js` — animaciones: preloader, logo animado, scroll horizontal, parallax, cursor, acordeón de servicios
- `assets/img/` — logotipos vectoriales (SVG) y fotografías optimizadas (WebP)

El formulario de contacto abre el correo del usuario dirigido a hello@leabstudios.com.
